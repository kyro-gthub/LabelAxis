# Keyboard shortcuts

## Files and windows

| Keys | Does |
|---|---|
| `Ctrl+N` | New project |
| `Ctrl+O` | Open a project |
| `Ctrl+S` / `Ctrl+Shift+S` | Save / Save as |
| `Ctrl+P` | Print |
| `Ctrl+Shift+P` | Print preview |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Next / previous open project |
| `Ctrl+W` | Close the project on screen |
| `F1` | This help guide |

## Editing

| Keys | Does |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | Undo / redo |
| `Ctrl+X`, `Ctrl+C`, `Ctrl+V` | Cut, copy, paste |
| `Ctrl+D` | Duplicate |
| `Delete` | Delete |
| `Ctrl+A` | Select everything |
| `Ctrl+G` / `Ctrl+Shift+G` | Group / ungroup |
| `Ctrl+L` | Lock or unlock |
| `Ctrl+B` / `Ctrl+Shift+B` | Bring to front / send to back |
| `Ctrl+Shift+T` | Free transform (slant with the side handles) |
| Arrow keys | Nudge one grid step (`Shift`: ten) |
| `Enter` or `F2` | Edit the selected text on the label |
| `Ctrl+F` / `Ctrl+H` | Find / find and replace |

## Pages, data and view

| Keys | Does |
|---|---|
| `F2` | Rename the page (in the page list) |
| `Ctrl+↑` / `Ctrl+↓` | Move the page, or the object in the list, up / down |
| `Ctrl+T` | Data records |
| `F5` | Refresh the data |
| Mouse wheel, `Ctrl++` / `Ctrl+-` | Zoom in / out (`Ctrl`+wheel scrolls) |
| `Ctrl+1` / `Ctrl+0` | Fit the label / actual size |
| `Space` + drag | Move around the label |

## While dragging

| Keys | Does |
|---|---|
| `Shift` | Keep proportions; straight lines; 15° rotation steps |
| `Ctrl` | Resize from the centre |
| `Alt` | Rotate with any handle |
