# कीबोर्ड शॉर्टकट

## फ़ाइलें और विंडो

| कुंजियाँ | काम |
|---|---|
| `Ctrl+N` | नया प्रोजेक्ट |
| `Ctrl+O` | प्रोजेक्ट खोलें |
| `Ctrl+S` / `Ctrl+Shift+S` | सहेजें / इस रूप में सहेजें |
| `Ctrl+P` | प्रिंट |
| `Ctrl+Shift+P` | प्रिंट पूर्वावलोकन |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | अगला / पिछला खुला प्रोजेक्ट |
| `Ctrl+W` | स्क्रीन वाला प्रोजेक्ट बंद करें |
| `F1` | यह सहायता गाइड |

## संपादन

| कुंजियाँ | काम |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | अनडू / फिर से करें |
| `Ctrl+X`, `Ctrl+C`, `Ctrl+V` | काटें, कॉपी करें, चिपकाएँ |
| `Ctrl+D` | डुप्लिकेट करें |
| `Delete` | हटाएँ |
| `Ctrl+A` | सब चुनें |
| `Ctrl+G` / `Ctrl+Shift+G` | समूह बनाएँ / समूह हटाएँ |
| `Ctrl+L` | लॉक या अनलॉक करें |
| `Ctrl+B` / `Ctrl+Shift+B` | सबसे आगे लाएँ / सबसे पीछे भेजें |
| `Ctrl+Shift+T` | मुक्त ट्रांसफ़ॉर्म (किनारे के हैंडल से तिरछा) |
| तीर कुंजियाँ | एक ग्रिड चरण खिसकाएँ (`Shift`: दस) |
| `Enter` या `F2` | लेबल पर चुना टेक्स्ट संपादित करें |
| `Ctrl+F` / `Ctrl+H` | खोजें / खोजें और बदलें |

## पेज, डेटा और दृश्य

| कुंजियाँ | काम |
|---|---|
| `F2` | पेज का नाम बदलें (पेज सूची में) |
| `Ctrl+↑` / `Ctrl+↓` | पेज, या सूची में ऑब्जेक्ट, ऊपर / नीचे ले जाएँ |
| `Ctrl+T` | डेटा रिकॉर्ड |
| `F5` | डेटा रीफ़्रेश करें |
| माउस व्हील, `Ctrl++` / `Ctrl+-` | ज़ूम इन / आउट (`Ctrl`+व्हील स्क्रॉल करता है) |
| `Ctrl+1` / `Ctrl+0` | लेबल फ़िट करें / वास्तविक आकार |
| `Space` + खींचें | लेबल पर घूमें |

## खींचते समय

| कुंजियाँ | काम |
|---|---|
| `Shift` | अनुपात बनाए रखें; सीधी रेखाएँ; 15° के घुमाव चरण |
| `Ctrl` | केंद्र से आकार बदलें |
| `Alt` | किसी भी हैंडल से घुमाएँ |
