# 键盘快捷键

## 文件和窗口

| 按键 | 作用 |
|---|---|
| `Ctrl+N` | 新建项目 |
| `Ctrl+O` | 打开项目 |
| `Ctrl+S` / `Ctrl+Shift+S` | 保存 / 另存为 |
| `Ctrl+P` | 打印 |
| `Ctrl+Shift+P` | 打印预览 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 下一个 / 上一个打开的项目 |
| `Ctrl+W` | 关闭屏幕上的项目 |
| `F1` | 本帮助指南 |

## 编辑

| 按键 | 作用 |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+X`、`Ctrl+C`、`Ctrl+V` | 剪切、复制、粘贴 |
| `Ctrl+D` | 复制一份 |
| `Delete` | 删除 |
| `Ctrl+A` | 全选 |
| `Ctrl+G` / `Ctrl+Shift+G` | 组合 / 取消组合 |
| `Ctrl+L` | 锁定或解锁 |
| `Ctrl+B` / `Ctrl+Shift+B` | 置于顶层 / 置于底层 |
| `Ctrl+Shift+T` | 自由变换（用侧边控点倾斜） |
| 方向键 | 微移一个网格步长（`Shift`：十步） |
| `Enter` 或 `F2` | 在标签上编辑所选文字 |
| `Ctrl+F` / `Ctrl+H` | 查找 / 查找和替换 |

## 页面、数据和视图

| 按键 | 作用 |
|---|---|
| `F2` | 重命名页面（在页面列表中） |
| `Ctrl+↑` / `Ctrl+↓` | 上移 / 下移页面或列表中的对象 |
| `Ctrl+T` | 数据记录 |
| `F5` | 刷新数据 |
| 鼠标滚轮、`Ctrl++` / `Ctrl+-` | 放大 / 缩小（`Ctrl`+滚轮为滚动） |
| `Ctrl+1` / `Ctrl+0` | 适应标签 / 实际大小 |
| `Space` + 拖动 | 在标签上移动视图 |

## 拖动时

| 按键 | 作用 |
|---|---|
| `Shift` | 保持比例；画直线；以 15° 步进旋转 |
| `Ctrl` | 从中心调整大小 |
| `Alt` | 用任意控点旋转 |
