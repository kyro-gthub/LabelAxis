# Wi-Fi 和网络打印机

LabelAxis 可以直接打印到 Wi-Fi 或办公网络中的打印机，无需安装驱动程序。近十年生产的大多数打印机都支持（提供 AirPrint、Mopria 或 IPP Everywhere 的打印机）。

## 添加 Wi-Fi 打印机

1. 在“打印”窗口中按 `Wi-Fi 打印机…`。
2. 按 `查找我网络中的打印机`，或输入打印机的地址（例如 **192.168.1.40**，可在打印机的网络设置页上找到），然后按 `查找`。
3. 在列表中选择打印机，然后按 `添加到我的打印机`。

现在它会以 **Wi-Fi：型号（地址）** 的形式出现在“打印”窗口的打印机列表中。选中它，像平常一样按“打印”即可。

## 打印方式

每张纸都完全按照预览绘制，并以打印机的分辨率、实际尺寸（从不缩小以适应页面）以及您的份数和纸张尺寸发送。只接受 PDF 的打印机会收到这些纸张的 PDF。

> 提示：如果 Wi-Fi 打印机打印时略有偏差，可像其他打印机一样校准：它同样出现在 `打印 › 打印机校准向导…` 中，校正值会用于发送给它的每个任务。

## 改为在 Windows 中安装

`打开 Windows 打印机设置…` 会打开 Windows 自己的“打印机和扫描仪”页面，在那里 `添加设备` 可以找到 Wi-Fi 打印机。在那里添加的打印机会出现在所有程序中，包括 LabelAxis。

## 找不到？

- 打印机和本机必须在同一网络中（访客 Wi-Fi 网络通常会将设备隔离）。
- 唤醒打印机，或尝试输入其地址。
- 使用 Wi-Fi 的热敏标签打印机应在热敏打印窗口中设置；请参阅 [[thermal|热敏标签打印机]]。
