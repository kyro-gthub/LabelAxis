# 热敏标签打印机

热敏打印机（Zebra、TSC、Xprinter 等）从卷筒打印标签。请从 `文件 › 新建热敏标签…` 开始，设置标签尺寸、卷筒横向放几个标签以及标签之间的间距。之后 `打印` 会打开热敏打印窗口（也可通过 `打印 › 热敏打印（ZPL / TSPL）…`）。

## 打印机

- **打印机语言：** Zebra 和“兼容 ZPL”的打印机用 ZPL；TSC、Xprinter 及许多桌面打印机用 TSPL。
- **发送到：**
  - **Windows 打印机：** 在 Windows 中安装的打印机。
  - **网络（IP 地址）：** 网络或 Wi-Fi 中的打印机。`查找打印机…` 会搜索您的网络；`测试` 检查该地址是否响应。
  - **Bluetooth 或串口（COM）：** 见下文。
  - **文件：** 将打印机命令保存为 .zpl / .prn 文件。
- **分辨率：** 203、300 或 600 dpi，与打印机标签上标注的一致。

## 蓝牙打印机

1. 打开打印机，并在 **Windows 设置 › 蓝牙和其他设备** 中配对。
2. Windows 会为已配对的打印机分配一个 COM 端口。在热敏打印窗口中选择 **Bluetooth 或串口（COM）**，然后选择标有 **Bluetooth** 的端口（配对后按 `↻ 重新查找` 刷新列表）。
3. 按 `测试`；端口打开后，打印机即可使用。

> 注意：一些通过手机应用控制的廉价标签打印机使用自己的私有蓝牙系统，而不是 ZPL 或 TSPL；这类打印机无法通过电脑程序使用。

## 介质和质量

- **标签检测：** 标签间隙、黑标或连续卷纸。
- **打印之后：** 撕纸、剥离或切纸。
- **移动打印位置：** 将打印内容稍微向右/向下移动以校正打印机；**倒置打印** 用于反向出纸的卷筒。
- **浓度** 和 **速度：** 更深、更慢可得到更清晰的条码。
- **灰色变为：** 清晰（适合文字和条码）或灰阶（适合照片）。

右侧的预览会准确显示打印机将收到的点阵。
