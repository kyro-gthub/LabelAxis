# 文字

单击工具栏上的 `文字` 即可添加文本框。

## 输入和编辑

- **双击** 文字（或在选中时按 `Enter` 或 `F2`）即可直接在标签上输入。在这里可以选中单个词，设为粗体、斜体、彩色或其他字号。完成后在外部单击或按 `Esc`。
- `属性 › 文字设置` 下的文本框也可以编辑文字。

## 文字外观

在 `文字设置` 中：字体、字号、**B** / *I* / 下划线 / 删除线、颜色、突出显示、对齐方式（左、中、右、两端；上、中、下）、行距、字间距和内边距。

**突出显示** 会填满文字后面的整个文本框。单击旁边的 `…` 可选择一种颜色，或选择 **渐变** 让两种颜色相互过渡。

> 注意：在面板中更改样式会应用到整个文本框，包括单独设置了格式的文字。

## 您自己的字体

单击字体列表旁的 `添加字体…`，选择字体文件（`.ttf` 或 `.otf`）：该字体会添加到 LabelAxis 中（无需在 Windows 中安装），并应用到所选文字。之后它会出现在所有字体列表中，在屏幕、打印和 PDF 文件中都可使用。`文件 › 设置 › 字体` 列出您添加的字体，并可删除它们。

使用此类字体的项目会在内部保留一份副本，因此在另一台电脑上看起来也一样：在那里打开项目时会自动添加该字体。

## 文字放不下时

`内容溢出时` 决定如何处理：

- **扩大文本框**（新文本框）：文本框变高，使所有文字都留在框内。拖动侧边控点会重新换行，高度随之变化。
- **缩小文字**：文字变小直到放得下，最小到 `最小（pt）` 中设定的字号。
- **允许溢出**：文本框保持原大小。

## 阿拉伯语等从右到左的文字

输入阿拉伯语（或希伯来语）时，段落会自动从右到左排列：字母相连，词语从右往左读，数字和英文单词保持各自的顺序。请参阅 [[arabic|阿拉伯语文字和字体]]。

## 在其他页面使用相同格式

`将此格式应用到其他页…`（位于文字设置底部，或在 `编辑` 菜单中）可将所选文本框的字体、字号、样式和颜色，以及（如需要）对齐方式和间距，应用到其他页面的文本框：每页上 **同名** 的文本框，或那里的 **所有文本框**。请参阅 [[pages|页面]]。

## 用数据改变文字

将字段名放在花括号中，例如 `{Product}`，每张打印出的标签就会显示电子表格中的该列。请参阅 [[data|数据和可变标签]]。
