# 条码和 QR 码

工具栏上的 `条码` 和 `QR Code` 可向标签添加条码。其设置位于 `属性 › 条码设置`。

## 类型

| 类型 | 用途 |
|---|---|
| EAN-13、EAN-8、UPC-A、UPC-E、ISBN-13 | 零售商品 |
| Code 128（A、B、C）、GS1-128 | 物流、库存、序列号 |
| Code 39、Code 93、Codabar、Interleaved 2 of 5、ITF-14、MSI Plessey | 较旧的系统和行业系统 |
| QR Code、Data Matrix、PDF417、Aztec | 网址、长文本、小零件 |

## 设置

- **数据：** 条码所包含的内容。可以是 `{Barcode}` 这样的字段，使每张标签都有自己的条码。
- **人可读文字：** 条下方打印的数字，以及它们的字体和字号。
- **颜色：** 保持浅色背景上的深色条；扫描器需要足够的对比度。

如果数据不适合该类型（例如 EAN-13 中含有字母），条码会显示为红色轮廓，面板中会说明原因。

> 提示：不要把条码缩小到其类型所需的尺寸以下；扫描器难以读取过窄的条。大批量打印前运行 `打印 › 打印前检查…` 以发现问题。

## 一次生成大量条码

`数据 › 批量条码生成器…` 会为每个值（可加前缀、后缀和补位）生成一个条码图片文件，保存到文件夹中。`数据 › 条码图片…` 可将单个条码保存为 PNG 图片（150 到 1200 dpi）、SVG 图形或 PDF。

## GS1 条码：食品、药品、医疗器械、物流

`数据 › GS1 条码生成器…`（或条码设置中的按钮）可以正确地制作 GS1 条码。选择标签用途，例如带有效期和批号的食品、医疗器械（UDI）、药品包装、纸箱或托盘（SSCC），然后填写每一行：

- 长度错误、校验位错误、不存在的日期以及需要搭配其他数据的数据，都会在输入时用通俗的话提示。`添加校验位` 会为您自动计算。
- 日期可以输入为 31/12/2026，会自动转为 YYMMDD。
- 选择 **GS1-128**（条形，用于纸箱和食品）、**GS1 DataMatrix**（小方形，用于药品和医疗器械）或 **GS1 QR Code**。对于方形码，还可以按医疗器械的要求在旁边以文字写出数据。
- 值可以是 `{Batch}` 这样的数据字段：打印时会为每张标签填入。

## 检测打印的条码

`数据 › 检测打印的条码…` 会像条码检测仪一样，为打印的条码评定 A（最好）到 F 级。启动摄像头并将标签放在它前面，或打开照片或扫描件。您会看到：

- 条码的内容，以及它是否与您正在设计的页面上的某个条码相同；
- 每项测量（对比度、调制比、缺陷、可解码度、静区、条宽）及其等级；
- 需要改进的地方，例如条打印得太宽时降低打印机的浓度。

这是可靠的参考，而非证书：光线和对焦会影响结果，请多检测几次。
