# 阿拉伯语文字和字体

## 书写阿拉伯语

在任意文本框中输入阿拉伯语即可。以阿拉伯语（或希伯来语）字母开头的段落会自动从右到左排列：

- 字母会正确相连；
- 词语从右往左读，换行后的文字也从右侧继续；
- 数字以及型号名称等英文单词，在阿拉伯语中保持各自的顺序。

若要让整个文本框不论以什么开头都从右到左排列，请将 `文字设置 › 方向` 设为 **从右到左**。

> 提示：对齐方式不会自动更改：对于应靠右边缘的阿拉伯语文字，请在 `对齐` 下选择 **右**。

**字间距** 永远不会把阿拉伯字母拉开，因为那样会破坏连写。

## LabelAxis 自带的阿拉伯语字体

以下五种字体内置在 LabelAxis 中，因此无论 Windows 是否安装了它们，标签在每台电脑上看起来都一样：

| 字体 | 风格 |
|---|---|
| Tajawal | 简洁现代，阅读轻松 |
| IBM Plex Sans Arabic | 现代，商务风格 |
| Almarai | 醒目；适合价格和标题 |
| Amiri | 经典纳斯赫体，正式 |
| Scheherazade New | 传统纳斯赫体，非常易读 |

它们与 Windows 中安装的字体一起出现在所有字体列表中（Windows 本身通常带有 Tahoma、Arial、Segoe UI、Dubai、Traditional Arabic 等）。

## 打印和 PDF

阿拉伯语在纸张、热敏打印机和 PDF 文件中的打印和导出效果与屏幕上完全一致。在导出的 PDF 中，阿拉伯语文字还可以被选中、复制，并可用阅读器的查找功能搜索。
