# 故障排除

## 标签打印位置不对

- 检查所选的 **标签纸** 是否与纸张包装盒上的型号一致。
- 保持 **缩放** 为 100%，并在打印机自带的设置中关闭“适应页面”。
- 为该打印机运行 [[calibration|校准向导]]。

## 文字被截断或太小

查看文字设置中的 `内容溢出时`：**扩大文本框** 可让所有文字保持可见。选择 **缩小文字** 时，字号会变小直到放得下。缩小文字或扩大文本框，直到所有内容都显示出来。

## 字体在另一台电脑上看起来不同

另一台电脑没有该字体。LabelAxis 自带的字体（五种阿拉伯语字体和程序自己的字体）始终存在，而用 `添加字体…` 添加的字体会随项目一起携带，在那台电脑上打开项目时会自动添加。对于只安装在 Windows 中的字体，请在那台电脑上也安装，或用 `添加字体…` 添加其文件，让项目带上它。打印前检查会提示缺少的字体。

## 图片打印模糊

图片的像素对于其打印尺寸来说太少；图片设置中会显示其 DPI。请使用更大的图片，或将其打印得更小。

## 条码无法扫描

把它放大，保持浅色背景上的深色条，在周围留出空白，在热敏打印机上打印得更深一些。检查数据是否适合该条码类型（[[barcodes|条码]]）。

## 列表中没有打印机

请在 Windows 中安装它；如果是网络打印机，请在 `Wi-Fi 打印机…` 中添加（[[wifi-printers|Wi-Fi 打印机]]）。热敏和蓝牙打印机：请参阅 [[thermal|热敏标签打印机]]。

## 安装时出现“Windows 已保护你的电脑”

对于 Windows 尚不认识的发布者的程序，Windows 会显示此提示。选择 **更多信息**，然后选择 **仍要运行**。

## 没有提示更新

- 检查 `文件 › 设置… › 更新` 中是否设置了 **更新地址**，或此版本是否内置了地址，以及电脑能否访问它。
- 尝试 `帮助 › 检查更新…`：提示信息会说明哪里出了问题。
- 便携版不会自动更新；请参阅 [[files|项目、保存和设置]]。

## 出现了其他问题

LabelAxis 会将您的工作安全地保存在恢复快照中，并把详细信息写入日志文件（位于 `%LOCALAPPDATA%\LabelAxis\logs`）。重新启动程序，并接受恢复工作的提示。
