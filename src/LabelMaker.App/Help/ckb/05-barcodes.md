# باڕکۆد و کۆدی QR

`باڕکۆد` و `QR Code` لە شریتی ئامرازەکاندا یەکێک زیاد دەکەن بۆ لەیبڵەکە. ڕێکخستنەکانی لە ژێر `تایبەتمەندییەکان › ڕێکخستنەکانی باڕکۆد`دان.

## جۆرەکان

| جۆر | بۆ |
|---|---|
| EAN-13, EAN-8, UPC-A, UPC-E, ISBN-13 | بەرهەمی فرۆشگا |
| Code 128 (A, B, C), GS1-128 | ناردن، کۆگا، ژمارەی زنجیرەیی |
| Code 39, Code 93, Codabar, Interleaved 2 of 5, ITF-14, MSI Plessey | سیستەمە کۆن و پیشەسازییەکان |
| QR Code, Data Matrix, PDF417, Aztec | بەستەری وێب، دەقی درێژ، پارچەی بچووک |

## ڕێکخستنەکان

- **داتا:** ئەوەی باڕکۆدەکە هەڵیدەگرێت. دەکرێت خانەیەک بێت وەک `{Barcode}` بۆ ئەوەی هەر لەیبڵێک بەهای خۆی هەبێت.
- **دەقی خوێندراو:** ئەو ژمارانەی لە ژێر هێڵەکانەوە چاپ دەکرێن، لەگەڵ فۆنت و قەبارەیان.
- **ڕەنگەکان:** هێڵی تۆخ لەسەر باکگراوندی کاڵ بهێڵەوە؛ سکانەرەکان پێویستیان بەو جیاوازییە هەیە.

ئەگەر داتاکە لەگەڵ جۆرەکە نەگونجێت (بۆ نموونە پیت لە EAN-13دا)، باڕکۆدەکە بە چوارچێوەیەکی سوور دەکێشرێت و پانێڵەکە هۆکارەکەی دەڵێت.

> Tip: باڕکۆد لە قەبارەیەک بچووکتر مەکەرەوە کە جۆرەکەی پێویستیەتی؛ سکانەرەکان هێڵی باریک بە خراپی دەخوێننەوە. پێش کارێکی گەورە `چاپ › پشکنینی پێش چاپ…` بەکاربهێنە بۆ دۆزینەوەی کێشەکان.

## زۆر باڕکۆد بە یەکجار

`داتا › دروستکەری باڕکۆدی بە کۆمەڵ…` بۆ هەر بەهایەک پەڕگەیەکی وێنەی باڕکۆد (لەگەڵ پێشگر، پاشگر و پڕکردنەوە بە سفر) لە بوخچەیەکدا پاشەکەوت دەکات. `داتا › وێنەی باڕکۆد…` یەک باڕکۆد وەک وێنەی PNG (لە 150 تا 1200 خاڵ لە ئینچێکدا)، وێنەکێشانی SVG یان PDF پاشەکەوت دەکات.
