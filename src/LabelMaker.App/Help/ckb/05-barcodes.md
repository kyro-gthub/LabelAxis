# باڕکۆد و کۆدی QR

`باڕکۆد` و `QR Code` لە شریتی ئامرازەکاندا یەکێک زیاد دەکەن بۆ لەیبڵەکە. ڕێکخستنەکانی لە ژێر `تایبەتمەندییەکان › ڕێکخستنەکانی باڕکۆد`دان.

## جۆرەکان

| جۆر | بۆ |
|---|---|
| EAN-13, EAN-8, UPC-A, UPC-E, ISBN-13 | بەرهەمی فرۆشگا |
| Code 128 (A, B, C), GS1-128 | ناردن، کۆگا، ژمارەی زنجیرەیی |
| Code 39, Code 93, Codabar, Interleaved 2 of 5, ITF-14, MSI Plessey | سیستەمە کۆن و پیشەسازییەکان |
| QR Code, Data Matrix, PDF417, Aztec | بەستەری وێب، دەقی درێژ، پارچەی بچووک |

## ڕێکخستنەکان

- **داتا:** ئەوەی باڕکۆدەکە هەڵیدەگرێت. دەکرێت خانەیەک بێت وەک `{Barcode}` بۆ ئەوەی هەر لەیبڵێک بەهای خۆی هەبێت.
- **دەقی خوێندراو:** ئەو ژمارانەی لە ژێر هێڵەکانەوە چاپ دەکرێن، لەگەڵ فۆنت و قەبارەیان.
- **ڕەنگەکان:** هێڵی تۆخ لەسەر باکگراوندی کاڵ بهێڵەوە؛ سکانەرەکان پێویستیان بەو جیاوازییە هەیە.

ئەگەر داتاکە لەگەڵ جۆرەکە نەگونجێت (بۆ نموونە پیت لە EAN-13دا)، باڕکۆدەکە بە چوارچێوەیەکی سوور دەکێشرێت و پانێڵەکە هۆکارەکەی دەڵێت.

> Tip: باڕکۆد لە قەبارەیەک بچووکتر مەکەرەوە کە جۆرەکەی پێویستیەتی؛ سکانەرەکان هێڵی باریک بە خراپی دەخوێننەوە. پێش کارێکی گەورە `چاپ › پشکنینی پێش چاپ…` بەکاربهێنە بۆ دۆزینەوەی کێشەکان.

## زۆر باڕکۆد بە یەکجار

`داتا › دروستکەری باڕکۆدی بە کۆمەڵ…` بۆ هەر بەهایەک پەڕگەیەکی وێنەی باڕکۆد (لەگەڵ پێشگر، پاشگر و پڕکردنەوە بە سفر) لە بوخچەیەکدا پاشەکەوت دەکات. `داتا › وێنەی باڕکۆد…` یەک باڕکۆد وەک وێنەی PNG (لە 150 تا 1200 خاڵ لە ئینچێکدا)، وێنەکێشانی SVG یان PDF پاشەکەوت دەکات.

## باڕکۆدەکانی GS1: خۆراک، دەرمان، ئامێری پزیشکی، ناردن

`داتا › دروستکەری باڕکۆدی GS1…` (یان دوگمەکە لە ڕێکخستنەکانی باڕکۆد) باڕکۆدی GS1 بە شێوەی دروست دروست دەکات. هەڵبژێرە لەیبڵەکە بۆ چییە، وەک خۆراک بە بەرواری بەسەرچوون و وەجبە، ئامێری پزیشکی (UDI)، پاکەتی دەرمان، کارتۆن یان پالێت (SSCC)، پاشان هەر دێڕێک پڕ بکەرەوە:

- درێژیی هەڵە، ژمارەی پشکنین، بەرواری نەبوو و ئەو داتایەی پێویستی بە داتای تر هەیە، لە کاتی نووسیندا بە وشەی ڕوون پیشان دەدرێن. `زیادکردنی ژمارەی پشکنین` بۆت دەیدۆزێتەوە.
- بەروار دەتوانرێت وەک 31/12/2026 بنووسرێت؛ دەبێت بە YYMMDD.
- **GS1-128** (هێڵ، بۆ کارتۆن و خۆراک)، **GS1 DataMatrix** (چوارگۆشەی بچووک، بۆ دەرمان و ئامێری پزیشکی) یان **GS1 QR** هەڵبژێرە. بۆ کۆدی چوارگۆشە داتاکە دەتوانرێت وەک دەقیش لە تەنیشتی بنووسرێت، وەک ئامێری پزیشکی پێویستی پێیەتی.
- بەهایەک دەتوانێت خانەیەکی داتا بێت وەک `{Batch}`: لە کاتی چاپکردندا بۆ هەر لەیبڵێک پڕ دەکرێتەوە.

## پشکنینی باڕکۆدێکی چاپکراو

`داتا › پشکنینی باڕکۆدێکی چاپکراو…` باڕکۆدێکی چاپکراو لە A (باشترین) تا F هەڵدەسەنگێنێت، وەک ئامێرێکی پشکنین. کامێراکە هەڵبکە و لەیبڵەکە لە بەردەمیدا بگرە، یان وێنە یان سکانێک بکەرەوە. دەبینیت:

- باڕکۆدەکە چی دەڵێت، و ئایا وەک باڕکۆدێکی ئەو لاپەڕەیەیە کە دیزاینی دەکەیت؛
- هەر پێوانەیەک (جیاوازیی ڕەنگ، ڕێکیی ڕەنگ، کەموکوڕی، توانای خوێندنەوە، ناوچە بەتاڵەکان، پانیی هێڵ) لەگەڵ پلەکەی؛
- چی بگۆڕیت، بۆ نموونە کەمکردنەوەی تۆخیی چاپکەر کاتێک هێڵەکان زۆر پان چاپ دەکرێن.

ڕێنمایییەکی نزیکە، نەک بڕوانامە: ڕووناکی و ڕوونی ئەنجامەکە دەگۆڕن، بۆیە چەند جارێک بپشکنە.
