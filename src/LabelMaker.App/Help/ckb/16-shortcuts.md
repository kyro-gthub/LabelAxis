# کورتبڕەکانی تەختەکلیل

## پەڕگە و پەنجەرەکان

| کلیلەکان | کار |
|---|---|
| `Ctrl+N` | پڕۆژەی نوێ |
| `Ctrl+O` | کردنەوەی پڕۆژەیەک |
| `Ctrl+S` / `Ctrl+Shift+S` | پاشەکەوتکردن / پاشەکەوتکردن وەک |
| `Ctrl+P` | چاپ |
| `Ctrl+Shift+P` | پێشبینینی چاپ |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | پڕۆژە کراوەی دواتر / پێشوو |
| `Ctrl+W` | داخستنی پڕۆژەی سەر شاشە |
| `F1` | ئەم ڕێبەری یارمەتییە |

## دەستکاریکردن

| کلیلەکان | کار |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | گەڕانەوە / دووبارەکردنەوە |
| `Ctrl+X`، `Ctrl+C`، `Ctrl+V` | بڕین، لەبەرگرتنەوە، لکاندن |
| `Ctrl+D` | دووانەکردن |
| `Delete` | سڕینەوە |
| `Ctrl+A` | دیاریکردنی هەموو |
| `Ctrl+G` / `Ctrl+Shift+G` | گرووپکردن / هەڵوەشاندنەوەی گرووپ |
| `Ctrl+L` | قوفڵکردن یان کردنەوەی قوفڵ |
| `Ctrl+B` / `Ctrl+Shift+B` | هێنانە پێشەوەی هەموو / ناردنە دواوەی هەموو |
| `Ctrl+Shift+T` | گۆڕینی ئازاد (لاری بە دەستکە لاتەنیشتەکان) |
| کلیلەکانی تیر | جووڵاندنی یەک هەنگاوی تۆڕ (`Shift`: دە هەنگاو) |
| `Enter` یان `F2` | دەستکاریکردنی دەقی دیاریکراو لەسەر لەیبڵەکە |
| `Ctrl+F` / `Ctrl+H` | گەڕان / گەڕان و گۆڕینەوە |

## لاپەڕە، داتا و پیشاندان

| کلیلەکان | کار |
|---|---|
| `F2` | ناوگۆڕینی لاپەڕە (لە لیستی لاپەڕەکاندا) |
| `Ctrl+↑` / `Ctrl+↓` | بردنی لاپەڕەکە، یان تەنەکە لە لیستەکەدا، بۆ سەرەوە / خوارەوە |
| `Ctrl+T` | تۆمارەکانی داتا |
| `F5` | نوێکردنەوەی داتا |
| خولی ماوس، `Ctrl++` / `Ctrl+-` | گەورەکردن / بچووککردنەوە (`Ctrl`+خول دەجووڵێنێت) |
| `Ctrl+1` / `Ctrl+0` | گونجاندنی لەیبڵ / قەبارەی ڕاستەقینە |
| `Space` + ڕاکێشان | جووڵان بە دەوری لەیبڵەکەدا |

## لە کاتی ڕاکێشاندا

| کلیلەکان | کار |
|---|---|
| `Shift` | پاراستنی ڕێژەکان؛ هێڵی ڕاست؛ سووڕانەوە بە هەنگاوی 15° |
| `Ctrl` | گۆڕینی قەبارە لە ناوەندەوە |
| `Alt` | سووڕاندنەوە بە هەر دەستکێک |
