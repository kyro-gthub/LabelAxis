# داتا و لەیبڵی گۆڕاو

بۆ هەر ڕیزێکی خشتەیەک یان بنکەدراوەیەک لەیبڵێکی جیاواز چاپ بکە: ناو، نرخ، باڕکۆد، ژمارەی زنجیرەیی.

## پەیوەستکردنی داتاکەت

- `داتا › هاوردەکردنی CSV / Excel…` پەڕگەیەکی ‎.csv یان ‎.xlsx دەخوێنێتەوە.
- `داتا › پەیوەندیکردن بە بنکەدراوە…` لە SQL Server، MySQL / MariaDB، PostgreSQL، SQLite، Microsoft Access یان هەر سەرچاوەیەکی ODBC دەخوێنێتەوە. `دەستکاریکردنی پەیوەندی…` دەیگۆڕێت؛ `F5` تۆمارەکان نوێ دەکاتەوە.
- `داتا › تۆمارەکان…` (`Ctrl+T`) ڕیزەکان پیشان دەدات؛ لەوێ دەستکارییان بکە، هەڵیانبژێرە کامیان چاپ بکرێن، یان تەنها دیاریکراوەکان چاپ بکە.

## دانانی خانەکان لەسەر لەیبڵ

ناوی ستوونەکە لەناو کەوانەی لووتکەداردا لە هەر دەق یان باڕکۆدێکدا بنووسە: `{Product}`، `{Price}`، `{Barcode}`. `داتا › زیادکردنی خانەی داتا…` یەکێکت بۆ دادەنێت. لەیبڵی سەر شاشە تۆماری ئێستا پیشان دەدات؛ تیرەکانی شریتی دۆخ یەک یەک بە ناو تۆمارەکاندا دەڕۆن.

## خانە ئامادەکان

| خانە | پیشان دەدات |
|---|---|
| `{TODAY}` / `{NOW}` | ڕێکەوتی ئەمڕۆ / ڕێکەوت و کات |
| `{RECORDNUMBER}` / `{RECORDCOUNT}` | ژمارەی ئەم تۆمارە / چەند تۆمار هەن |
| `{PAGENUMBER}` / `{LABELPOSITION}` | ژمارەی پەڕە / شوێنی لەیبڵەکە لەسەر پەڕەکە |

## هەژمارکردن

لەناو کەوانەکاندا دەتوانیت فەنکشنیش بەکاربهێنیت، بۆ نموونە `{UPPER(Product)}`، `{ROUND(Price * 1.15, 2)}`، `{IF(Stock > 0, "هەیە", "نەماوە")}`، `{DATEFORMAT(ADDDAYS(TODAY(), 30), "dd/MM/yyyy")}`. هی تر: LOWER، TRIM، LEFT، RIGHT، MID، CONCAT، REPLACE، PADLEFT، FORMAT، MIN، MAX، ABS، YEAR، MONTH، DAY، ADDMONTHS، IFEMPTY، CONTAINS، STARTSWITH.

## ژمارەی زنجیرەیی

`داتا › بەڕێوەبردنی زنجیرەکان…` ژمێرەر ڕێک دەخات: دەستپێک، کۆتایی، هەنگاو، و پێشگر یان پاشگرێک. یەکێکیان بە ناوەکەی لەناو کەوانەدا بەکاربهێنە؛ بۆ هەر لەیبڵێکی چاپکراو یەکێک زیاد دەبێت.

## پێش چاپکردن

`داتا › پشکنینی دووبارەبوونەوە…` ئەو تۆمارانە دەدۆزێتەوە کە هەمان بەها دوو جار چاپ دەکەن، وەک دوو لەیبڵ بە هەمان باڕکۆد. بۆ چاپکردنی لەیبڵێک بۆ هەر تۆمارێک، لە پەنجەرەی چاپدا **لەیبڵێک بۆ هەر تۆمارێکی داتا** هەڵبژێرە؛ سەیری [[printing|چاپکردن]] بکە.
