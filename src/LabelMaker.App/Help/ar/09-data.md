# البيانات والملصقات المتغيرة

اطبع ملصقًا مختلفًا لكل صف في جدول بيانات أو قاعدة بيانات: أسماء، وأسعار، وباركود، وأرقام تسلسلية.

## ربط بياناتك

- يقرأ `البيانات › استيراد CSV / Excel…` ملف ‎.csv أو ‎.xlsx.
- يقرأ `البيانات › الاتصال بقاعدة بيانات…` من SQL Server أو MySQL / MariaDB أو PostgreSQL أو SQLite أو Microsoft Access أو أي مصدر ODBC. يغيّره `تعديل الاتصال…`؛ ويحدّث `F5` السجلات.
- يعرض `البيانات › السجلات…` (`Ctrl+T`) الصفوف؛ عدّلها هناك، واختر ما يُطبع منها، أو اطبع المحدد منها فقط.

## وضع الحقول على الملصق

اكتب اسم العمود بين قوسين معقوفين في أي نص أو باركود: `{Product}` و`{Price}` و`{Barcode}`. ويدرج `البيانات › إضافة حقل بيانات…` حقلًا لك. يعرض الملصق على الشاشة السجل الحالي؛ وتتنقّل الأسهم في شريط الحالة بين السجلات.

## حقول جاهزة

| الحقل | يعرض |
|---|---|
| `{TODAY}` / `{NOW}` | تاريخ اليوم / التاريخ والوقت |
| `{RECORDNUMBER}` / `{RECORDCOUNT}` | رقم هذا السجل / عدد السجلات |
| `{PAGENUMBER}` / `{LABELPOSITION}` | رقم الورقة / موضع الملصق على الورقة |

## العمليات الحسابية

داخل الأقواس يمكنك أيضًا استخدام دوال، مثل `{UPPER(Product)}` و`{ROUND(Price * 1.15, 2)}` و`{IF(Stock > 0, "متوفر", "نفد")}` و`{DATEFORMAT(ADDDAYS(TODAY(), 30), "dd/MM/yyyy")}`. وغيرها: LOWER وTRIM وLEFT وRIGHT وMID وCONCAT وREPLACE وPADLEFT وFORMAT وMIN وMAX وABS وYEAR وMONTH وDAY وADDMONTHS وIFEMPTY وCONTAINS وSTARTSWITH.

## الأرقام التسلسلية

يُعدّ `البيانات › إدارة التسلسلات…` العدادات: البداية والنهاية والخطوة، وبادئة أو لاحقة. استخدم العداد باسمه بين قوسين؛ فيزيد واحدًا مع كل ملصق مطبوع.

## قبل الطباعة

يجد `البيانات › فحص التكرار…` السجلات التي ستطبع القيمة نفسها مرتين، مثل ملصقين بالباركود نفسه. لطباعة ملصق لكل سجل، اختر **ملصق لكل سجل بيانات** في نافذة الطباعة؛ راجع [[printing|الطباعة]].
