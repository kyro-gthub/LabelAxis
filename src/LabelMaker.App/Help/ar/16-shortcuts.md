# اختصارات لوحة المفاتيح

## الملفات والنوافذ

| المفاتيح | الوظيفة |
|---|---|
| `Ctrl+N` | مشروع جديد |
| `Ctrl+O` | فتح مشروع |
| `Ctrl+S` / `Ctrl+Shift+S` | حفظ / حفظ باسم |
| `Ctrl+P` | طباعة |
| `Ctrl+Shift+P` | معاينة الطباعة |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | المشروع المفتوح التالي / السابق |
| `Ctrl+W` | إغلاق المشروع المعروض |
| `F1` | دليل المساعدة هذا |

## التحرير

| المفاتيح | الوظيفة |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | تراجع / إعادة |
| `Ctrl+X`، `Ctrl+C`، `Ctrl+V` | قص، نسخ، لصق |
| `Ctrl+D` | تكرار |
| `Delete` | حذف |
| `Ctrl+A` | تحديد الكل |
| `Ctrl+G` / `Ctrl+Shift+G` | تجميع / فك التجميع |
| `Ctrl+L` | قفل أو إلغاء القفل |
| `Ctrl+B` / `Ctrl+Shift+B` | إحضار إلى المقدمة / إرسال إلى الخلفية |
| `Ctrl+Shift+T` | تحويل حر (الإمالة بالمقابض الجانبية) |
| مفاتيح الأسهم | تحريك خطوة شبكة واحدة (`Shift`: عشر خطوات) |
| `Enter` أو `F2` | تحرير النص المحدد على الملصق |
| `Ctrl+F` / `Ctrl+H` | بحث / بحث واستبدال |

## الصفحات والبيانات والعرض

| المفاتيح | الوظيفة |
|---|---|
| `F2` | إعادة تسمية الصفحة (في قائمة الصفحات) |
| `Ctrl+↑` / `Ctrl+↓` | نقل الصفحة، أو العنصر في القائمة، لأعلى / لأسفل |
| `Ctrl+T` | سجلات البيانات |
| `F5` | تحديث البيانات |
| عجلة الفأرة، `Ctrl++` / `Ctrl+-` | تكبير / تصغير (`Ctrl`+العجلة للتمرير) |
| `Ctrl+1` / `Ctrl+0` | ملاءمة الملصق / الحجم الفعلي |
| `Space` + سحب | التنقّل حول الملصق |

## أثناء السحب

| المفاتيح | الوظيفة |
|---|---|
| `Shift` | الحفاظ على النسب؛ خطوط مستقيمة؛ تدوير بخطوات 15° |
| `Ctrl` | تغيير الحجم من المركز |
| `Alt` | التدوير بأي مقبض |
