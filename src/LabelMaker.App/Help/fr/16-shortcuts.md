# Raccourcis clavier

## Fichiers et fenêtres

| Touches | Action |
|---|---|
| `Ctrl+N` | Nouveau projet |
| `Ctrl+O` | Ouvrir un projet |
| `Ctrl+S` / `Ctrl+Shift+S` | Enregistrer / Enregistrer sous |
| `Ctrl+P` | Imprimer |
| `Ctrl+Shift+P` | Aperçu avant impression |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Projet ouvert suivant / précédent |
| `Ctrl+W` | Fermer le projet affiché |
| `F1` | Ce guide d'aide |

## Édition

| Touches | Action |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | Annuler / rétablir |
| `Ctrl+X`, `Ctrl+C`, `Ctrl+V` | Couper, copier, coller |
| `Ctrl+D` | Dupliquer |
| `Delete` | Supprimer |
| `Ctrl+A` | Tout sélectionner |
| `Ctrl+G` / `Ctrl+Shift+G` | Grouper / dissocier |
| `Ctrl+L` | Verrouiller ou déverrouiller |
| `Ctrl+B` / `Ctrl+Shift+B` | Premier plan / arrière-plan |
| `Ctrl+Shift+T` | Transformation libre (incliner avec les poignées latérales) |
| Flèches | Décaler d'un pas de grille (`Shift` : dix) |
| `Enter` ou `F2` | Modifier le texte sélectionné sur l'étiquette |
| `Ctrl+F` / `Ctrl+H` | Rechercher / rechercher et remplacer |

## Pages, données et affichage

| Touches | Action |
|---|---|
| `F2` | Renommer la page (dans la liste des pages) |
| `Ctrl+↑` / `Ctrl+↓` | Monter / descendre la page, ou l'objet dans la liste |
| `Ctrl+T` | Enregistrements de données |
| `F5` | Actualiser les données |
| Molette, `Ctrl++` / `Ctrl+-` | Zoom avant / arrière (`Ctrl`+molette fait défiler) |
| `Ctrl+1` / `Ctrl+0` | Ajuster l'étiquette / taille réelle |
| `Space` + glisser | Se déplacer sur l'étiquette |

## Pendant le glisser

| Touches | Action |
|---|---|
| `Shift` | Garder les proportions ; lignes droites ; rotation par pas de 15° |
| `Ctrl` | Redimensionner depuis le centre |
| `Alt` | Faire pivoter avec n'importe quelle poignée |
