# Арабский текст и шрифты

## Набор на арабском

Набирайте арабский текст в любом текстовом поле. Абзац, начинающийся с арабской (или еврейской) буквы, сам идёт справа налево:

- буквы соединяются как положено;
- слова читаются справа, а перенесённые строки продолжаются справа;
- числа и английские слова, например название модели, сохраняют свой порядок внутри арабского текста.

Чтобы всё текстовое поле шло справа налево независимо от начала, задайте `Параметры текста › Направление` = **Справа налево**.

> Совет: выравнивание не меняется само: выберите **По правому краю** в `Выровнять` для арабского текста, который должен прилегать к правому краю.

**Межбуквенный интервал** никогда не раздвигает арабские буквы, потому что это разорвало бы соединения.

## Арабские шрифты в комплекте LabelAxis

Эти пять шрифтов встроены в LabelAxis, поэтому этикетки выглядят одинаково на любом ПК, есть они в Windows или нет:

| Шрифт | Стиль |
|---|---|
| Tajawal | Чистый и современный, лёгкий для чтения |
| IBM Plex Sans Arabic | Современный, деловой |
| Almarai | Плотный; хорош для цен и заголовков |
| Amiri | Классический насх, официальный |
| Scheherazade New | Традиционный насх, очень читаемый |

Они есть во всех списках шрифтов рядом со шрифтами, установленными в Windows (в самой Windows часто есть Tahoma, Arial, Segoe UI, Dubai, Traditional Arabic и другие).

## Печать и PDF

Арабский текст печатается и экспортируется точно так, как выглядит на экране, — на листах, термопринтерах и в PDF-файлах. В экспортированном PDF арабские слова также можно выделять, копировать и находить поиском просмотрщика.
