# Страницы: несколько этикеток в одном проекте

Проект может содержать несколько разных макетов этикеток — **страниц**; они перечислены в разделе `Страницы` слева и пронумерованы 1, 2, 3… Первая страница — это ещё и **основная этикетка**: та, что повторяется по листу при печати «Заполнить лист».

## Работа со страницами

- `+` добавляет пустую страницу; кнопка дублирования копирует страницу на экране.
- Дважды щёлкните страницу (или нажмите `F2`), чтобы переименовать её на месте.
- `Ctrl+↑` / `Ctrl+↓` или перетаскивание меняют порядок.
- Длинный список страниц прокручивается колесом мыши или стрелками вверх и вниз на концах полосы прокрутки.
- Кнопка удаления удаляет страницу на экране. Первую страницу тоже можно удалить, пока есть другие; тогда следующая становится страницей 1.
- Чтобы найти страницу по названию, нажмите `Ctrl+F` и введите его часть: названия страниц ищутся вместе со всем остальным (**Названия страниц** в «Где искать»). Выберите совпадение, чтобы открыть страницу; **Заменить** переименовывает её.

> Совет: сделайте одну этикетку, затем **дублируйте** её для каждого товара и меняйте только текст. Дублированные страницы сохраняют имена своих объектов, по которым инструмент ниже находит «тот же» объект на каждой странице.

## Придать другим страницам формат этой страницы

`Правка › Применить формат страницы к другим страницам…` (также по щелчку правой кнопкой на странице и на вкладке `Страница`) делает другие страницы похожими на страницу на экране. Каждое текстовое поле, штрихкод, изображение, фигура и таблица там получают положение, размер и вид своего соответствия на этой странице и **сохраняют свой текст, значение штрихкода и изображение**.

- **Копировать с:** все объекты этой страницы или только выбранные.
- **Что копировать:**
  - **Положение**, **размер**, **поворот и наклон**.
  - **Внешний вид и параметры:** шрифт и цвета, тип штрихкода, высота штрихов и цифры под ними, вписывание и рамка изображения, контур и заливка фигуры, линии и текст таблицы. Для текста можно выбрать части: шрифт, размер текста, полужирный/курсив/подчёркнутый, цвета, выравнивание, междустрочный и межбуквенный интервал.
  - **Добавить объекты, которых нет на странице:** объект этой страницы без соответствия на другой странице копируется туда вместе с текстом и изображением.
- **Какие объекты:** текст, штрихкоды и QR-коды, изображения, фигуры и таблицы — каждый включается отдельно.
- **Сопоставлять:** по **имени, иначе по порядку** (рекомендуется); только по **имени**; или только по **порядку** (первое текстовое поле с первым, второй штрихкод со вторым). QR-код сопоставляется только с QR-кодом, а линейный штрихкод — только с линейным.
- **Какие страницы:** отметьте их; у каждой указано, сколько объектов изменится и сколько добавится.

Тип штрихкода, который не может вместить значение страницы (EAN-13 для букв «ABC»), этой странице не навязывается; штрихкод получает остальной вид.

## Удалить объект со всех страниц

Чтобы убрать что-то со всех этикеток сразу, например старый штрихкод, логотип или текстовое поле с именем «Акция», выделите его на одной странице и выберите `Правка › Удалить со всех страниц…` (также по щелчку правой кнопкой на нём на этикетке или в `Слои`).

- **Удалить и с этой страницы** удаляет и сам выбранный объект; снимите отметку, чтобы оставить его здесь.
- **Сопоставлять** находит тот же объект на других страницах: по **имени, иначе по порядку** (рекомендуется), только по **имени** или только по **порядку**.
- **Какие страницы:** отметьте их; у каждой указано, сколько объектов будет удалено.

Заблокированные объекты не удаляются никогда.

## То же форматирование текста на других страницах

`Правка › Применить форматирование текста к другим страницам…` копирует шрифт, размер, начертание и цвет выделенного текстового поля на другие страницы. См. [[text|Текст]].

Каждый из этих инструментов — один шаг отмены: `Ctrl+Z` возвращает все страницы.
