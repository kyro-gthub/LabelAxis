# Сочетания клавиш

## Файлы и окна

| Клавиши | Действие |
|---|---|
| `Ctrl+N` | Новый проект |
| `Ctrl+O` | Открыть проект |
| `Ctrl+S` / `Ctrl+Shift+S` | Сохранить / Сохранить как |
| `Ctrl+P` | Печать |
| `Ctrl+Shift+P` | Предварительный просмотр |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Следующий / предыдущий открытый проект |
| `Ctrl+W` | Закрыть проект на экране |
| `F1` | Это руководство |

## Правка

| Клавиши | Действие |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | Отменить / повторить |
| `Ctrl+X`, `Ctrl+C`, `Ctrl+V` | Вырезать, копировать, вставить |
| `Ctrl+D` | Дублировать |
| `Delete` | Удалить |
| `Ctrl+A` | Выделить всё |
| `Ctrl+G` / `Ctrl+Shift+G` | Сгруппировать / разгруппировать |
| `Ctrl+L` | Заблокировать или разблокировать |
| `Ctrl+B` / `Ctrl+Shift+B` | На передний план / на задний план |
| `Ctrl+Shift+T` | Свободное преобразование (наклон боковыми маркерами) |
| Клавиши со стрелками | Сдвиг на шаг сетки (`Shift`: на десять) |
| `Enter` или `F2` | Изменить выделенный текст на этикетке |
| `Ctrl+F` / `Ctrl+H` | Найти / найти и заменить |

## Страницы, данные и вид

| Клавиши | Действие |
|---|---|
| `F2` | Переименовать страницу (в списке страниц) |
| `Ctrl+↑` / `Ctrl+↓` | Переместить страницу или объект в списке вверх / вниз |
| `Ctrl+T` | Записи данных |
| `F5` | Обновить данные |
| Колесо мыши, `Ctrl++` / `Ctrl+-` | Увеличить / уменьшить (`Ctrl`+колесо прокручивает) |
| `Ctrl+1` / `Ctrl+0` | Вписать этикетку / фактический размер |
| `Space` + перетаскивание | Перемещение по этикетке |

## При перетаскивании

| Клавиши | Действие |
|---|---|
| `Shift` | Сохранять пропорции; прямые линии; поворот шагами по 15° |
| `Ctrl` | Менять размер от центра |
| `Alt` | Поворот любым маркером |
