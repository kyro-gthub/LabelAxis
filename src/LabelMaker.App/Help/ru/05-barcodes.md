# Штрихкоды и QR-коды

`Штрихкод` и `QR Code` на панели инструментов добавляют его на этикетку. Параметры — в разделе `Свойства › Параметры штрихкода`.

## Типы

| Тип | Применение |
|---|---|
| EAN-13, EAN-8, UPC-A, UPC-E, ISBN-13 | Розничные товары |
| Code 128 (A, B, C), GS1-128 | Доставка, склад, серийные номера |
| Code 39, Code 93, Codabar, Interleaved 2 of 5, ITF-14, MSI Plessey | Старые и отраслевые системы |
| QR Code, Data Matrix, PDF417, Aztec | Веб-ссылки, длинный текст, мелкие детали |

## Параметры

- **Данные:** что содержит штрихкод. Это может быть поле, например `{Barcode}`, чтобы у каждой этикетки был свой код.
- **Читаемый текст:** цифры под штрихами, с их шрифтом и размером.
- **Цвета:** оставляйте тёмные штрихи на светлом фоне; сканерам нужен контраст.

Если данные не подходят к типу (например, буквы в EAN-13), штрихкод рисуется красным контуром, а на панели объясняется причина.

> Совет: не уменьшайте штрихкод ниже размера, нужного для его типа; сканеры плохо читают узкие штрихи. Перед большим заданием запустите `Печать › Проверка перед печатью…`, чтобы найти проблемы.

## Много штрихкодов сразу

`Данные › Массовая генерация штрихкодов…` сохраняет в папку файл изображения штрихкода для каждого значения (с префиксом, суффиксом и дополнением нулями). `Данные › Изображение штрихкода…` сохраняет один штрихкод как изображение PNG (от 150 до 1200 dpi), рисунок SVG или PDF.

## Штрихкоды GS1: продукты, лекарства, медицинские изделия, доставка

`Данные › Конструктор штрихкодов GS1…` (или кнопка в параметрах штрихкода) создаёт штрихкоды GS1 по правилам. Выберите, для чего этикетка, например продукт со сроком годности и партией, медицинское изделие (UDI), упаковка лекарства, коробка или паллета (SSCC), и заполните каждую строку:

- Неверная длина, контрольные цифры, несуществующие даты и данные, которым нужны другие данные, показываются простыми словами прямо при вводе. `Добавить контрольную цифру` вычислит её за вас.
- Даты можно вводить как 31/12/2026; они превращаются в ГГММДД.
- Выберите **GS1-128** (штрихи, для коробок и продуктов), **GS1 DataMatrix** (маленький квадрат, для лекарств и медицинских изделий) или **GS1 QR Code**. Для квадратного кода данные можно также написать текстом рядом, как требуется для медицинских изделий.
- Значением может быть поле данных, например `{Batch}`: при печати оно заполняется для каждой этикетки.

## Проверка напечатанного штрихкода

`Данные › Проверить напечатанный штрихкод…` оценивает напечатанный штрихкод от A (лучше всего) до F, как это делает верификатор. Запустите камеру и поднесите к ней этикетку или откройте фото или скан. Вы увидите:

- что содержит штрихкод и совпадает ли он со штрихкодом на странице, которую вы создаёте;
- каждое измерение (контраст, модуляция, дефекты, декодируемость, свободные зоны, ширина штрихов) с оценкой;
- что изменить, например уменьшить плотность принтера, если штрихи печатаются слишком широкими.

Это хороший ориентир, а не сертификат: свет и фокус влияют на результат, поэтому проверьте несколько раз.
