# Данные и переменные этикетки

Печатайте отдельную этикетку для каждой строки электронной таблицы или базы данных: имена, цены, штрихкоды, серийные номера.

## Подключение данных

- `Данные › Импорт CSV / Excel…` читает файл .csv или .xlsx.
- `Данные › Подключиться к базе данных…` читает из SQL Server, MySQL / MariaDB, PostgreSQL, SQLite, Microsoft Access или любого источника ODBC. `Изменить подключение…` меняет его; `F5` обновляет записи.
- `Данные › Записи…` (`Ctrl+T`) показывает строки; правьте их там, выбирайте, какие печатать, или печатайте только выбранные.

## Поля на этикетке

Напишите имя столбца в фигурных скобках в любом тексте или штрихкоде: `{Product}`, `{Price}`, `{Barcode}`. `Данные › Добавить поле данных…` вставит его за вас. Этикетка на экране показывает текущую запись; стрелки в строке состояния переходят между записями.

## Готовые поля

| Поле | Показывает |
|---|---|
| `{TODAY}` / `{NOW}` | Сегодняшнюю дату / дату и время |
| `{RECORDNUMBER}` / `{RECORDCOUNT}` | Номер этой записи / сколько их всего |
| `{PAGENUMBER}` / `{LABELPOSITION}` | Номер листа / положение этикетки на листе |

## Вычисления

Внутри скобок можно использовать и функции, например `{UPPER(Product)}`, `{ROUND(Price * 1.15, 2)}`, `{IF(Stock > 0, "В наличии", "Нет в наличии")}`, `{DATEFORMAT(ADDDAYS(TODAY(), 30), "dd/MM/yyyy")}`. Другие: LOWER, TRIM, LEFT, RIGHT, MID, CONCAT, REPLACE, PADLEFT, FORMAT, MIN, MAX, ABS, YEAR, MONTH, DAY, ADDMONTHS, IFEMPTY, CONTAINS, STARTSWITH.

## Серийные номера

`Данные › Управление последовательностями…` настраивает счётчики: начало, конец, шаг и префикс или суффикс. Используйте счётчик по имени в скобках; он увеличивается на один с каждой напечатанной этикеткой.

## Перед печатью

`Данные › Проверить на дубликаты…` находит записи, которые напечатали бы одно и то же значение дважды, например две этикетки с одинаковым штрихкодом. Чтобы печатать по одной этикетке на запись, выберите **Одна этикетка на запись данных** в окне «Печать»; см. [[printing|Печать]].
