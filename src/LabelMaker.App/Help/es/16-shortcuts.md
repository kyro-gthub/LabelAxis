# Atajos de teclado

## Archivos y ventanas

| Teclas | Hace |
|---|---|
| `Ctrl+N` | Nuevo proyecto |
| `Ctrl+O` | Abrir un proyecto |
| `Ctrl+S` / `Ctrl+Shift+S` | Guardar / Guardar como |
| `Ctrl+P` | Imprimir |
| `Ctrl+Shift+P` | Vista previa de impresión |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Proyecto abierto siguiente / anterior |
| `Ctrl+W` | Cerrar el proyecto en pantalla |
| `F1` | Esta guía de ayuda |

## Edición

| Teclas | Hace |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | Deshacer / rehacer |
| `Ctrl+X`, `Ctrl+C`, `Ctrl+V` | Cortar, copiar, pegar |
| `Ctrl+D` | Duplicar |
| `Delete` | Eliminar |
| `Ctrl+A` | Seleccionar todo |
| `Ctrl+G` / `Ctrl+Shift+G` | Agrupar / desagrupar |
| `Ctrl+L` | Bloquear o desbloquear |
| `Ctrl+B` / `Ctrl+Shift+B` | Traer al frente / enviar al fondo |
| `Ctrl+Shift+T` | Transformación libre (inclinar con los tiradores laterales) |
| Flechas | Desplazar un paso de cuadrícula (`Shift`: diez) |
| `Enter` o `F2` | Editar el texto seleccionado en la etiqueta |
| `Ctrl+F` / `Ctrl+H` | Buscar / buscar y reemplazar |

## Páginas, datos y vista

| Teclas | Hace |
|---|---|
| `F2` | Renombrar la página (en la lista de páginas) |
| `Ctrl+↑` / `Ctrl+↓` | Subir / bajar la página, o el objeto en la lista |
| `Ctrl+T` | Registros de datos |
| `F5` | Actualizar los datos |
| Rueda del ratón, `Ctrl++` / `Ctrl+-` | Acercar / alejar (`Ctrl`+rueda desplaza) |
| `Ctrl+1` / `Ctrl+0` | Ajustar la etiqueta / tamaño real |
| `Space` + arrastrar | Moverse por la etiqueta |

## Al arrastrar

| Teclas | Hace |
|---|---|
| `Shift` | Mantener proporciones; líneas rectas; giro en pasos de 15° |
| `Ctrl` | Cambiar el tamaño desde el centro |
| `Alt` | Girar con cualquier tirador |
