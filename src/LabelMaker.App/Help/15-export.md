# Exporting and checking a job

## Save as a file

- `Print > Export > Sheet to PDF…` saves the job as a PDF with the same settings as printing (sheets, start position, records). Send it to a print shop, or keep it as proof.
- `Current label to PNG…` saves the label on screen as a picture; `Current label to SVG…` as a drawing that design programs open.

## Check before printing

`Print > Preflight check…` looks for problems before an expensive job: missing pictures or fonts, barcodes with wrong data or too big for the label, fields that are empty for a record, duplicate barcodes, and labels reaching past the area the printer can print.

## Bring in Microsoft Publisher files

`File > Open Publisher file (all pages)…` turns a Publisher (.pub) file into a project; `Import text and pictures from Publisher…` brings its contents into the open project.
