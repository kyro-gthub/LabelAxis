# داده و برچسب‌های متغیر

برای هر ردیف یک صفحه‌گسترده یا پایگاه‌داده برچسب متفاوتی چاپ کنید: نام، قیمت، بارکد، شماره سریال.

## وصل کردن داده‌ها

- `داده › ورود CSV / Excel…` یک فایل ‎.csv‎ یا ‎.xlsx‎ را می‌خواند.
- `داده › اتصال به پایگاه‌داده…` از SQL Server، MySQL / MariaDB، PostgreSQL، SQLite، Microsoft Access یا هر منبع ODBC می‌خواند. `ویرایش اتصال…` آن را تغییر می‌دهد؛ `F5` رکوردها را تازه می‌کند.
- `داده › رکوردها…` (`Ctrl+T`) ردیف‌ها را نشان می‌دهد؛ همان‌جا ویرایششان کنید، انتخاب کنید کدام‌ها چاپ شوند، یا فقط انتخاب‌شده‌ها را چاپ کنید.

## گذاشتن فیلد روی برچسب

نام ستون را در هر متن یا بارکدی میان آکولاد بنویسید: `{Product}`، `{Price}`، `{Barcode}`. `داده › افزودن فیلد داده…` یکی را برایتان درج می‌کند. برچسب روی صفحه‌نمایش رکورد فعلی را نشان می‌دهد؛ پیکان‌های نوار وضعیت میان رکوردها جابه‌جا می‌شوند.

## فیلدهای آماده

| فیلد | نشان می‌دهد |
|---|---|
| `{TODAY}` / `{NOW}` | تاریخ امروز / تاریخ و ساعت |
| `{RECORDNUMBER}` / `{RECORDCOUNT}` | شماره این رکورد / تعداد کل |
| `{PAGENUMBER}` / `{LABELPOSITION}` | شماره برگه / جای برچسب روی برگه |

## محاسبات

داخل آکولاد می‌توانید از تابع‌ها هم استفاده کنید، مثلاً `{UPPER(Product)}`، `{ROUND(Price * 1.15, 2)}`، `{IF(Stock > 0, "موجود", "ناموجود")}`، `{DATEFORMAT(ADDDAYS(TODAY(), 30), "dd/MM/yyyy")}`. بقیه: LOWER، TRIM، LEFT، RIGHT، MID، CONCAT، REPLACE، PADLEFT، FORMAT، MIN، MAX، ABS، YEAR، MONTH، DAY، ADDMONTHS، IFEMPTY، CONTAINS، STARTSWITH.

## شماره سریال

`داده › مدیریت شماره‌گذاری‌ها…` شمارنده‌ها را تنظیم می‌کند: شروع، پایان، گام و پیشوند یا پسوند. از هر کدام با نامش میان آکولاد استفاده کنید؛ با هر برچسب چاپ‌شده یکی بالا می‌رود.

## پیش از چاپ

`داده › بررسی تکراری‌ها…` رکوردهایی را پیدا می‌کند که یک مقدار را دو بار چاپ می‌کنند، مانند دو برچسب با یک بارکد. برای چاپ یک برچسب برای هر رکورد، در پنجره چاپ **یک برچسب برای هر رکورد داده** را انتخاب کنید؛ [[printing|چاپ]] را ببینید.
