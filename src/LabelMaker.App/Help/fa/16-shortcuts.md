# میان‌برهای صفحه‌کلید

## فایل‌ها و پنجره‌ها

| کلیدها | کار |
|---|---|
| `Ctrl+N` | پروژه جدید |
| `Ctrl+O` | باز کردن پروژه |
| `Ctrl+S` / `Ctrl+Shift+S` | ذخیره / ذخیره به نام |
| `Ctrl+P` | چاپ |
| `Ctrl+Shift+P` | پیش‌نمایش چاپ |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | پروژه باز بعدی / قبلی |
| `Ctrl+W` | بستن پروژه روی صفحه‌نمایش |
| `F1` | همین راهنما |

## ویرایش

| کلیدها | کار |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | واگرد / ازنو |
| `Ctrl+X`، `Ctrl+C`، `Ctrl+V` | برش، کپی، چسباندن |
| `Ctrl+D` | تکثیر |
| `Delete` | حذف |
| `Ctrl+A` | انتخاب همه |
| `Ctrl+G` / `Ctrl+Shift+G` | گروه کردن / لغو گروه |
| `Ctrl+L` | قفل یا باز کردن قفل |
| `Ctrl+B` / `Ctrl+Shift+B` | آوردن به جلوترین لایه / بردن به عقب‌ترین لایه |
| `Ctrl+Shift+T` | تبدیل آزاد (کج کردن با دستگیره‌های کناری) |
| کلیدهای جهت‌نما | جابه‌جایی یک گام شبکه (`Shift`: ده) |
| `Enter` یا `F2` | ویرایش متن انتخاب‌شده روی برچسب |
| `Ctrl+F` / `Ctrl+H` | یافتن / یافتن و جایگزینی |

## صفحه‌ها، داده و نما

| کلیدها | کار |
|---|---|
| `F2` | تغییر نام صفحه (در فهرست صفحه‌ها) |
| `Ctrl+↑` / `Ctrl+↓` | بردن صفحه یا شیء فهرست به بالا / پایین |
| `Ctrl+T` | رکوردهای داده |
| `F5` | تازه‌سازی داده |
| چرخ ماوس، `Ctrl++` / `Ctrl+-` | بزرگ‌نمایی / کوچک‌نمایی (`Ctrl`+چرخ پیمایش می‌کند) |
| `Ctrl+1` / `Ctrl+0` | جا دادن برچسب / اندازه واقعی |
| `Space` + کشیدن | حرکت روی برچسب |

## هنگام کشیدن

| کلیدها | کار |
|---|---|
| `Shift` | حفظ تناسب؛ خطوط صاف؛ چرخش در گام‌های 15 درجه |
| `Ctrl` | تغییر اندازه از مرکز |
| `Alt` | چرخاندن با هر دستگیره |
