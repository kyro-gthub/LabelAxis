# Sneltoetsen

## Bestanden en vensters

| Toetsen | Doet |
|---|---|
| `Ctrl+N` | Nieuw project |
| `Ctrl+O` | Een project openen |
| `Ctrl+S` / `Ctrl+Shift+S` | Opslaan / Opslaan als |
| `Ctrl+P` | Afdrukken |
| `Ctrl+Shift+P` | Afdrukvoorbeeld |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Volgend / vorig geopend project |
| `Ctrl+W` | Het project op het scherm sluiten |
| `F1` | Deze helpgids |

## Bewerken

| Toetsen | Doet |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | Ongedaan maken / opnieuw |
| `Ctrl+X`, `Ctrl+C`, `Ctrl+V` | Knippen, kopiëren, plakken |
| `Ctrl+D` | Dupliceren |
| `Delete` | Verwijderen |
| `Ctrl+A` | Alles selecteren |
| `Ctrl+G` / `Ctrl+Shift+G` | Groeperen / groep opheffen |
| `Ctrl+L` | Vergrendelen of ontgrendelen |
| `Ctrl+B` / `Ctrl+Shift+B` | Naar voorgrond / naar achtergrond |
| `Ctrl+Shift+T` | Vrij transformeren (hellen met de zijgrepen) |
| Pijltoetsen | Eén rasterstap verschuiven (`Shift`: tien) |
| `Enter` of `F2` | De geselecteerde tekst op het etiket bewerken |
| `Ctrl+F` / `Ctrl+H` | Zoeken / zoeken en vervangen |

## Pagina's, gegevens en weergave

| Toetsen | Doet |
|---|---|
| `F2` | De pagina hernoemen (in de paginalijst) |
| `Ctrl+↑` / `Ctrl+↓` | De pagina, of het object in de lijst, omhoog / omlaag |
| `Ctrl+T` | Gegevensrecords |
| `F5` | De gegevens vernieuwen |
| Muiswiel, `Ctrl++` / `Ctrl+-` | In- / uitzoomen (`Ctrl`+wiel schuift) |
| `Ctrl+1` / `Ctrl+0` | Etiket passend / werkelijke grootte |
| `Space` + slepen | Rondkijken over het etiket |

## Tijdens het slepen

| Toetsen | Doet |
|---|---|
| `Shift` | Verhoudingen behouden; rechte lijnen; draaien in stappen van 15° |
| `Ctrl` | Grootte wijzigen vanuit het midden |
| `Alt` | Draaien met elke greep |
