# Wi-Fi and network printers

LabelAxis can print straight to a printer on your Wi-Fi or office network, without installing a driver. Most printers made in the last ten years can do this (those that offer AirPrint, Mopria or IPP Everywhere).

## Add a Wi-Fi printer

1. In the Print window, press `Wi-Fi printers…`.
2. Press `Find printers on my network`, or type the printer's address (such as **192.168.1.40**, shown on the printer's network settings page) and press `Look up`.
3. Pick the printer in the list and press `Add to my printers`.

It now appears in the Print window's printer list as **Wi-Fi: model (address)**. Choose it and press Print as usual.

## How it prints

Each sheet is drawn exactly as the preview shows it and sent at the printer's resolution, at real size (never shrunk to fit), with your copies and paper size. Printers that only accept PDF receive a PDF of the same sheets.

> Tip: If a Wi-Fi printer prints slightly off, calibrate it like any other printer: it is listed in `Print > Printer Calibration Wizard…` too, and the correction is used for every job sent to it.

## Install it in Windows instead

`Open Windows printer settings…` opens Windows' own Printers & scanners page, where `Add device` finds Wi-Fi printers. A printer added there appears in every program, LabelAxis included.

## Not found?

- The printer and this PC must be on the same network (guest Wi-Fi networks often keep devices apart).
- Wake the printer up, or try its address.
- A thermal label printer on Wi-Fi is set up in the thermal print window instead; see [[thermal|Thermal label printers]].
