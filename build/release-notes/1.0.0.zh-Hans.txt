LabelAxis 1.0.0

新增功能
• LabelAxis 支持十种语言：英语、阿拉伯语、中库尔德语（索拉尼语）、波斯语、法语、西班牙语、荷兰语、俄语、简体中文和印地语，涵盖菜单、窗口、消息和帮助指南；阿拉伯语、库尔德语和波斯语从右到左排列。可在“文件 › 设置 › 语言”中选择，或让 LabelAxis 跟随 Windows 的语言。PDF、QR Code 和 Wi-Fi 等技术名称保持英文。
• 自动更新：LabelAxis 每天检查一次新版本，您选择“立即更新”时会为您安装。
• Wi-Fi 打印机现在也可以像其他打印机一样校准。
• 导出的 PDF 文件中的阿拉伯语文字可以选中、复制和搜索。
• 您自己的字体：用字体列表旁的“添加字体…”（或在“设置 › 字体”中）添加 .ttf 或 .otf 文件，无需在 Windows 中安装。使用该字体的项目会保留一份副本，因此在另一台电脑上看起来也一样。
• “文件 › 新建项目”的第一个选项卡中有 66 个现成的标签设计：价签、产品和条码标签、食品、物流、库存、学校、药房、胸牌以及 QR 标签，每个都配有专用的标签纸或卷筒。
• 全新外观：柔和彩色光晕上的透明玻璃面板，并提供八种主题（Frost、Aurora、Midnight、Graphite、Ember、Ocean、Sakura、Sage），可在设置中或通过窗口顶部的主题按钮切换。
• 自定义形状支持曲线：任何点都可以是平滑的曲线，而不是尖角。
• “新建项目”中还提供“自定义尺寸…”，可制作任意尺寸的标签。
• 将页面格式应用到其他页（“编辑”菜单，或右键单击页面）：其他页上的每个对象都会采用本页对应对象的位置、尺寸、旋转和外观——字体、颜色、条码类型和尺寸、边框——同时每页保留各自的文字、条码值和图片。还可以添加页面缺少的对象。
• 页面列表中的页面编号为 1、2、3……，第一页也有编号。
• 状态栏更整洁，在较小的屏幕上不再重叠。
• 颜色窗口中支持渐变：形状的填充和文本框的背景可以按任意角度混合两种颜色。可从 16 种现成渐变或最近使用的渐变中选择。
• 查找（Ctrl+F）也会搜索页面名称：选择结果即可打开该页面，“替换”可重命名页面。
• 条码图片生成器除 SVG 和 PDF 外，还可保存 PNG 图片（150 到 1200 dpi）。
• 您自己的设计：“文件 › 将页面另存为我的设计”可连同标签纸、字体、图片和数据连接一起保存页面。它会显示在“文件 › 新建项目”中“我的设计”下的最前面。
• GS1 条码生成器（“数据”菜单）：适用于食品、药品、医疗器械（UDI）和物流的 GS1-128、GS1 DataMatrix 和 GS1 QR 码，输入时即检查校验位、日期和所有 GS1 规则。GS1 DataMatrix 和 GS1 QR 码现在包含真正的 GS1 数据。
• 来自其他程序的打印请求（“打印”菜单）：收银机、网店或电子表格只需将 .json 或 .csv 文件放入监视文件夹，或发送到本机的网页链接，即可打印标签。可以打印，也可以返回 PDF。
• 自定义主题：“设置 › 制作自定义主题”（或主题按钮）可选择您的颜色、背景和光晕，并实时显示；文字颜色会自动选择，确保始终清晰可读。
• 从所有页面删除（“编辑”菜单，或右键单击对象）：一步将所选对象（例如旧条码或名为“优惠”的文本框）从本页和其他页面中删除，可按名称或顺序查找。撤销可还原；已锁定的对象会保留。
• 页面列表的滚动条带有上下箭头。
• 检测打印的条码（“数据”菜单）：通过摄像头、照片或扫描件，像条码检测仪一样为条码评定 A 到 F 级，并说明它是否与标签一致以及需要改进的地方。

下载更小
• 主安装程序现在小得多。在没有 Microsoft .NET 10 Desktop Runtime 的电脑上，它会从 Microsoft 下载一次；另外还提供包含全部内容的离线安装程序。

其他
• 新标签的示例文字使用界面语言。
• 屏幕阅读器会用界面语言朗读按钮和菜单。
• 最大化窗口时会正好铺满屏幕，在以前会盖住任务栏或够不到边缘的电脑上也是如此。
• 在“无颜色”之后选择颜色会得到可见的颜色；以前会一直透明。
• 导出的 PDF 文件中的渐变方向与屏幕上一致，并且可以渐隐至透明。
• 小标签上的长 GS1 条码会自动适应标签，任何条码下方的文字都会缩小到条的宽度。
• “关于 LabelAxis”现在只在“帮助”菜单中。
