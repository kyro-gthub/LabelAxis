LabelAxis — third-party software and fonts
==========================================

LabelAxis is built on the open-source components below. Each is used under its
own licence; the licence names are those the components publish. Full licence
texts are available at the addresses given (and, for fonts, in the "fonts"
folder next to this file).

Runtime
-------
  .NET runtime and Windows Desktop (WPF)        MIT          https://dot.net/
  System.Data.Odbc, System.Data.OleDb,
  System.IO.Ports                               MIT          https://dot.net/
